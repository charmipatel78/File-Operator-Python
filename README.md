# 📓 Personal Journal Manager

## 📖 Overview

This project is a simple command-line based journal manager built using Python.

It allows users to write, store, and manage personal journal entries in a file with timestamps.

---

## ✨ Key Features

📝 Add new journal entries with date and time
📂 View all saved entries
🔍 Search entries using keywords
🗑️ Delete all journal records
📋 Menu-driven interface for easy use

---

## 💾 File Handling

* Stores data in a text file (`journal.txt`)
* Uses append mode to save entries
* Reads and processes file content
* Handles missing file errors

---

## ⚙️ How It Works

* Each entry is saved with a timestamp
* Entries are stored line by line in a file
* Users can search entries using keywords
* File can be deleted to clear all data

---

## ▶️ How to Run

Run the program using:

python "File Operator.py"

---

This project helps you understand:

* File handling in Python
* Exception handling
* Working with timestamps (`datetime`)
* Building real-world CLI applications
